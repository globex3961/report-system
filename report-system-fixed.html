📋 如何从问卷星下载问卷数据？

  1. 登录 问卷星 wjx.cn → 进入问卷 → 点击「查看下载答卷」
  2. 选择「下载答卷数据」→ 下拉箭头 → 选择「按序号下载到Excel」
  3. 点击「立即下载到本地」
  4. 下载后点击下方「导入问卷结果」按钮，选择该文件即可

提示：如果你的问卷不是本系统生成的，导入后会弹出映射界面，为每道题指定对应的课程目标即可。

问卷一键发布

已生成问卷星批量导入文本，请按以下步骤操作：

  1. 点击「复制题目文本」按钮（已自动复制到剪贴板）
  2. 登录 问卷星 wjx.cn → 创建问卷 → 批量导入
  3. 粘贴文本 → 自动生成所有题目
  4. 发布问卷，问卷星自动生成二维码和微信分享链接
  5. 学生填写后，在问卷星导出Excel → 回到本系统「导入问卷结果」

已生成问卷填写页面，请按以下步骤操作：

  1. 点击下方按钮下载问卷页面文件
  2. 将文件上传到任意静态服务器（如 GitHub Pages、学校服务器等）
  3. 将文件访问链接粘贴到下方输入框
  4. 生成的二维码可保存图片后分享到微信群，学生扫码即可填写
